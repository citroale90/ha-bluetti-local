# Marchio BLUETTI

Le due immagini PNG originali sono riprese dalla cartella BLUETTI del repository Home Assistant Brands:

- https://github.com/home-assistant/brands/tree/master/custom_integrations/bluetti
- `icon.png`: immagine 256 × 256.
- `icon@2x.png`: immagine 512 × 512.

Sono usate per identificare il dispositivo compatibile, senza modifiche grafiche. Il marchio e le immagini BLUETTI appartengono ai rispettivi titolari; la licenza MIT del codice non attribuisce diritti sul marchio. Questa integrazione locale non è un prodotto ufficiale BLUETTI.

Il simbolo azzurro trasparente è adatto sia ai temi chiari sia a quelli scuri. Le richieste di logo o tema scuro usano il fallback nativo di Home Assistant verso queste immagini, senza dipendere dal CDN.
